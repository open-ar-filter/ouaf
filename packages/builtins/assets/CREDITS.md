# Built-in resources: credits and licences

The files of this folder are the engine's built-in resources (spec §10.3), referenced by filters as `builtin:<name>`.
They are served by the host next to the engine and loaded only when a filter uses them; the engine never fetches them
from a third party at runtime (spec §15). `scripts/make.sh` rebuilds the fonts from the pinned upstream sources
below; `scripts/build-luts.ts` generates the LUTs.

## Fonts (`fonts/`)

All under the [SIL Open Font License 1.1](https://openfontlicense.org), none with a Reserved Font Name. The full
licence, with each copyright notice, is in `licenses/OFL-<font>.txt`, and is also kept in each file's `name` table.

| Built-in | File | Font | Version | Copyright | Licence |
|---|---|---|---|---|---|
| `font/sans` | `sans.woff2` | Inter, weight 400 | 4.001 | 2016 The Inter Project Authors | `licenses/OFL-inter.txt` |
| `font/sans-bold` | `sans-bold.woff2` | Inter, weight 700 | 4.001 | 2016 The Inter Project Authors | `licenses/OFL-inter.txt` |
| `font/rounded-bold` | `rounded-bold.woff2` | Nunito, weight 700 | 3.602 | 2014 The Nunito Project Authors | `licenses/OFL-nunito.txt` |
| `font/serif` | `serif.woff2` | Noto Serif, weight 400 | 2.015 | 2022 The Noto Project Authors | `licenses/OFL-notoserif.txt` |
| `font/mono` | `mono.woff2` | JetBrains Mono, weight 400 | 2.211 | 2020 The JetBrains Mono Project Authors | `licenses/OFL-jetbrainsmono.txt` |
| `font/handwritten` | `handwritten.woff2` | Caveat, weight 500 | 2.000 | 2014 The Caveat Project Authors | `licenses/OFL-caveat.txt` |

Source: the variable fonts of the [Google Fonts repository](https://github.com/google/fonts) (`ofl/<font>/`), commit
`06bfe0d62a98375cb09c942fa18e68bd32cff057`. Modifications (Modified Versions in the OFL's sense, under the same
licence and the original names, which no Reserved Font Name restricts): instantiated at the weight above, hinting
removed, subset and converted to WOFF2 with [fontTools](https://github.com/fonttools/fonttools)
(`scripts/make-font.py`).

Coverage (code points kept when the font has them): Basic Latin, Latin-1, Latin Extended-A and -B, IPA and spacing
modifiers, combining diacritics, phonetic extensions, Latin Extended Additional (Vietnamese included), Latin
Extended-C and -D, Latin ligatures, general punctuation, currency symbols, letterlike symbols (™, №…), basic arrows.
That is Google Fonts' `latin`, `latin-ext` and `vietnamese` subsets. Greek and Cyrillic are not included. A character
missing from a built-in font falls back to the system fonts. Emoji are not built in: they are drawn with the
platform's emoji font (spec §6.3).

## LUTs (`luts/`)

`lut/vintage`, `lut/noir`, `lut/warm`, `lut/cool`, `lut/vivid`: our own work, generated by `scripts/build-luts.ts`
(`npm run build:luts -w @ouaf/builtins`) from the color grades defined in that script, and dedicated to the public
domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). 17×17×17 `.cube` files, input and output in
gamma-encoded sRGB.
